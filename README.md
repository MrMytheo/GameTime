## 已确认的目标

以「线条小狗」中的小白与小鸡毛为主角，让玩家分时体验两位主角的故事；通过「与此同时，另一边……」等转场连接两条叙事线。游戏按章节制作箱庭地图，使用空气墙限制可游玩区域。故事从真实相识经历展开，逐步延伸到虚构的未来余生。

- 平台：Windows 与 Linux 桌面版，目标设备配置待补充。
- 画风：采用「线条小狗」原作画风，角色与场景以原作视觉为参考；本次更正替代此前的泛化「简洁卡通」描述。
- 画面形式：用户确认采用可见修正版 v2 的 B，即 3D 描边与自由镜头方向；此版 B 作为当前美术基准，旧版 A 不作为制作依据。
- 角色形态：双脚与四脚混合，平时双脚活动，部分动作或情绪表现采用四脚姿态。
- 视角：剧情节点自动切换。
- 对应关系：用户为小鸡毛，伴侣为小白。
- 受众：先私人制作，以后再决定是否公开。
- 首章范围：从各自宿舍中的微信组队开始，延伸到线下活动结束；用户以「1 缺 3」招募，伴侣随后私聊确认加入。
- 对白：保留真实意思，允许润色、补写与创作；已收到一张群内招募截图，首次私聊及其他记录待补充。
- 玩法：探索、物品互动、剧情对话、双线解谜、日常小游戏、纪念物收集全部保留；按真实故事与章节需要安排。
