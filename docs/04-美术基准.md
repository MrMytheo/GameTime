## 1. 视觉基准

[查看概念图](../assets/visual-exploration/dorm-2d-vs-3d-v2.png)：以右列 B 为当前制作目标。原作画风要求继续生效，原作图片见 [参考记录](../references/line-puppy-original/README.md)。

- 3D 角色与 3D 环境，保留自由镜头目标。
- 清楚的黑色描边、简洁造型和克制的卡通明暗。
- 角色保留线条小狗的识别特征：小鸡毛为浅棕黄色、珊瑚红项圈，小白为白色；五官采用简洁黑色图形。
- 环境采用 B 的立体空间感，控制家具、纹理和装饰细节的密度。
- 双脚活动与部分四脚姿态的原先选择继续生效；概念图中的单一姿态不替代动作清单。

## 2. 场景与故事的关系

- 宿舍组队阶段，两位主角在各自的宿舍中，使用微信。
- 图中的房型、床品、装饰、设备颜色和具体姿势均为示意；真实布局和必要剧情物品在取得素材后确定。
- 「一人成军」属于招募记录；正式 UI 需要区分发送与查看消息，不能画成两人都发了同一句话。
- 线下城市活动的地点、路线与场景数量等待故事素材后确定。

## 3. 进入实际 3D 制作时的检查项

- 正面、侧面、背面及斜角观察时，两只角色的轮廓与五官保持一致。
- 不同镜头距离下描边清楚，角色不会与背景混在一起。
- 行走、转身、双脚与四脚姿态切换时，形体和面部保持可辨识。
- 自由镜头在宿舍墙面与家具附近能看清角色和交互点。
- 在 Windows/Linux 目标设备上检查实际运行效果。
