# 首个可玩原型计划

状态：首轮方向已确认，首章素材和原型范围待补齐。

## 1. 本轮需要证明的体验

玩家能够操控两位主角，在有限的箱庭空间内完成可理解的目标，经历一次双视角衔接，并到达明确的结束状态。

候选范围：一个短章节、两个角色视角、每个视角至少一个交互点、一次视角衔接、一个章节结束节点。视角所在空间可相同或不同，依据真实事件确定。

用户已选从第一次线上联系开始：跨校联谊活动前，两位主角各自在宿舍中使用微信，用户在群里以「1 缺 3」独立招募，伴侣私聊确认加入。第一章延伸到线下活动结束。对白原文等用户查找后补，已允许保留真实意思后润色、补写与创作。

第一章完整范围已确认；首个内部验证场景仍可先接通宿舍双线，具体迭代拆分待首章流程明确后安排。

用户选择全部六类玩法：探索、物品互动、剧情对话、双线解谜、日常小游戏、纪念物收集，并确认按真实故事安排。第一章采用与事件适配的玩法，其余留在后续章节。

候选安排：组队与首次私聊对应探索、物品互动和对话；城市定向解密与双线解谜的结合、日常打卡与小游戏的结合、纪念物收集的时机均属于设计草案，需在获得后续素材后确认。

## 4. 双线状态设计注意点

已选剧情自动切换，以下为需要覆盖的规则：

- 当前控制的角色、镜头跟随对象、交互提示和目标提示保持一致。
- 两位角色各自的已完成交互得到保留；共享事件有明确的生效条件。
- 对话或转场中是否允许切换、移动、继续交互，要提前明确。
- 每次自动切换要给出具体触发条件，并定义两位角色可用的地点、等待状态以及互相解锁条件。
- 切换后的出生位置或保留位置有明确规则，避免越界或落在障碍物内部。
